# Pajó Agenda

Protótipo independente da Agenda Digital.

## Incluído na v1
- Vista diária inspirada numa agenda clássica
- Tarefas e compromissos com hora
- Notas diárias
- Vista mensal clicável
- Planeador anual
- Persistência local através de `localStorage`
- Layout responsivo para computador e telemóvel

Nesta fase não existe ligação à Pajo Home nem sincronização cloud.
